# Lentil_Phenology_GWAS
This project contains phenotypic (phenological: days to flower; days to maturity) and genetic data used to perform GWAS on a 307-member lentil population that was evaluated in five environments in South Carolina.
It also contains a file with the scored allele and p-value for each SNP for all models and environments included in the final analysis
(n=5 PCs included as covariates; GLM and SUPER models not included in final analysis due to the high likelihood of false positives). 
A description of each environment can be found here: https://doi.org/10.1002/csc2.70272.
